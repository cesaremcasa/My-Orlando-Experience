# Architecture (v0.4.0)

My Orlando AgentOps is a local-first FastAPI service:

1. `POST /query` — grounded retrieval baseline (unchanged).
2. `POST /agent/chat` — ADK Sequential/Parallel graph: retrieval+memory in parallel, Grok `LiteLlm` response, structured safety, memory write only after PASS.
3. `POST /feedback` — allowlisted beta feedback in local SQLite.
4. Optional Phoenix/OTLP export when `PHOENIX_COLLECTOR_ENDPOINT` is set.

Memory: SQLite is authoritative. Production local search rebuilds an in-memory FAISS `IndexFlatIP` from user-filtered rows. Vertex Memory Bank is an unprovisioned Pre-GA adapter.

Provider: xAI Grok only. Vertex BYOR eval consumes responses already generated by Grok. Gemini is not a production fallback.

GCP: **NOT PROVISIONED / APPROVAL REQUIRED**.
